# Front End Department / Back End Course / Group A1

## What the Course Is About

Back End training for Front End developers aims to raise competencies in line with current market requirements and to build a T-Shaped profile (a broad outlook with deep expertise in a key area).

> The assignment is the same for all participants, ***however, any part of it may be personally adjusted in agreement with the mentor.***

## Tools

Any tools, including artificial intelligence, may be used at all stages of implementation. At the same time, the participant must be prepared to fully and reasonedly justify every technical decision made during the intermediate and final reviews with the mentor. If the tools differ from those recommended in the assignment, they must be agreed upon with the mentor.

## Mentors

Each participant is assigned a mentor based on their level of preparation and location. Every week, the mentor collects the current development status of the practical assignment.

> ***At any stage of the training, participants may turn to the mentor for theoretical and technical consultations.*** To arrange a meeting, contact the mentor and schedule a time via the calendar. In addition, when in the same office as the mentor, you can approach them directly offline without prior arrangement.

### Final Result

By the end of the course, you will have a backend service: a monolithic HTTP API with a relational database, access checks for operations, and background jobs. A separate frontend is not needed — all scenarios are invoked from an HTTP client.

The service registers users and, if required, confirms their email, performs login with access and refresh cookies, manages roles and permissions, and authorizes protected operations. A user reads and changes their profile and deletes their account; an administrator maintains the user list, roles, and other users' profiles. The same service transforms text files and images, returns the operation history, and, on request, saves the results to object storage.
